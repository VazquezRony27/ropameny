# ModaUrbana – PWA de venta de ropa
Catálogo, filtro por categoría, búsqueda, carrito persistente (localStorage), checkout simulado, modo offline e instalable.

## Publicar (GitHub Pages)
1. Subir el CONTENIDO de esta carpeta a un repositorio (index.html en la raíz).
2. Settings → Pages → Deploy from branch → main / root.
3. URL: https://USUARIO.github.io/REPO/
Alternativas: Netlify Drop, Cloudflare Pages, Vercel.

## Probar
- Local: `python -m http.server 8000` y abrir http://localhost:8000 (localhost cuenta como contexto seguro).
- Lighthouse → PWA/Installability. Al cambiar archivos, subir la versión de CACHE en sw.js.
